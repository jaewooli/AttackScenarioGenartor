# WBS 2.2-A 얇은 엔진 검토

2026-11-23

## 변경사항

- 검증된 인프라 IR에서 추상 상태 사실을 도출하는 결정론적 프로토타입을 추가했다. 사실 집합과 도출 근거를 안정된 순서로 반환한다.
- 외부 서비스 노출(R10)은 후속 평가 후보로 기록한다. 후보는 확정 사실 집합에 추가되지 않는다.
- 합성 테스트 10개와 원본 `shop-hybrid` 통합 테스트 1개를 추가했다.

## 통합 검증

- 전체 pytest 86개 통과. 기존 회귀 75개와 추가 테스트 11개를 포함한다.
- `scengen validate docs/samples/shop-hybrid.ir.yaml` 오류 0개, 경고 0개.
- 통합 테스트는 각 프로필에서 결과가 생성되고 동일한 입력에 동일한 결과가 나오는지 확인한다.

## WBS 2.2 설계 초안

규칙 결과는 아래 세 가지로 정의하는 안을 검토한다.

| 결과 | 기록할 내용 |
|---|---|
| 확정 사실 | 사실의 유형과 인자, 도출 규칙 ID, 전제 사실, 근거 관계 |
| 평가 후보 | 후보 규칙 ID, 관측 근거, 아직 확인할 조건 |
| 미평가 | 지원하지 않는 필드나 조건과 해당 사유 |

조건부 권한과 거부 우선순위, 그룹 상속, 관계의 포트·프로토콜·경유 조건은 별도 의미론이 필요하다. 확률 분포와 `known_state` 처리도 보류한다. 규칙 DSL 확정 전에 어떤 조건에서 평가를 보류하는지 명시하고, 여러 근거가 있을 때 결과에서 각 근거를 확인할 수 있도록 표현 형식을 정의한다.
