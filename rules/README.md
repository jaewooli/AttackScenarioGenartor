# WBS 2.3 초기 규칙셋

각 YAML 파일은 DSL v1 규칙 하나다. 입력 IR에 선언된 관계를 바탕으로 확인할 대상을 기록한다. 네 규칙은 후보를 생성하며, 전이 성공률은 자료가 확보될 때까지 보류한다. 그룹 대상은 선언된 그룹 단위로 기록한다.

| 규칙 | 적용 범위 |
|---|---|
| network-reach | 기존 시작 사실과 출발점이 일치하는 연결의 도달성 검토 |
| permission-scope | 명시적으로 허용된 정규화 행위의 유효 범위 검토 |
| stored-data-read | 같은 저장소의 읽기 권한과 데이터 포함 관계 대조 |
| discovery-uninformed | uninformed 변형에만 선택. 이미 아는 시작점에서 선언된 인접 대상의 발견 가능성 검토 |

프로필별 규칙 선택 시 informed에서는 discovery-uninformed를 제외한다. 이 목록은 P3 엔진에 전달할 선언형 산출물이다. 현재 Python 프로토타입은 자체 규칙을 사용한다.
